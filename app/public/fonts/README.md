# Matter

Matter (Displaay Type Foundry) is a commercial typeface and is **not** included here.
Drop your licensed web fonts in this folder with these exact names and the wallet will use them automatically:

    Matter-Regular.woff2   (400)
    Matter-Medium.woff2    (500)
    Matter-SemiBold.woff2  (600)
    Matter-Bold.woff2      (700)

Without them the app uses the system font, as Telegram's own clients do.
